Dino Tab
A super simple, lightweight browser start page built with basic HTML, CSS, and vanilla JS. No heavy frameworks, no bloated libraries, and no unnecessary tracking. Just a clean page with the basics you actually need when you open a new tab.

Features
Quick Search: A central search bar that goes straight to Google.

Clock & Greeting: Shows the time, date, and gives you a greeting based on the time of day.

Custom Bookmarks: Add and delete your own quick links. They save automatically to your browser's local storage.

Dino Themes: Switch between Triassic, Jurassic, and Cretaceous color schemes.

Daily Fact: Learn a random dinosaur fact every day.

Dino Run: A fully playable clone of the classic browser dinosaur game built right into the bottom of the page. Hit space to jump.

How to use it
Save the code as an index.html file.

Double-click it to open it in your browser.

Use a browser extension to set it as your default new tab page if you want to see it every time you open a tab.

Everything runs locally on your machine. No server or setup required.
