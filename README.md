🦖 DinoTab
Yo! Welcome to DinoTab — the ultimate Jurassic upgrade for your boring default browser page.

I got super tired of the plain Chrome homepage, so I built this. It turns every new tab into an immersive, interactive prehistoric jungle loaded with useful tools, dynamic themes, sound effects, and hidden secrets.

Quick Features
🔎 Central Search Bar: Works just like Google. Type your query, hit enter, boom—results.

⏰ Explorer Clock & Greeting: Real-time dynamic clock with greetings that adapt whether you're working early morning or pulling a late-night gaming session.

🦖 Interactive T-Rex (Meet Rexy!): Fully animated vector T-Rex with breathing, tail sway, and blinking eyes. Click on him to make him roar, shake the screen, and talk back!

🌿 Atmospheric Parallax Scene: Multi-layered SVG background featuring shifting mist, silhouette mountains, floating clouds, and flying pterodactyls that move with your mouse.

📌 Dino Trails (Shortcuts): Add, edit, or remove your favorite quick-access links (YouTube, Gmail, ChatGPT, etc.) with automatic favicons. Saved right to your browser's localStorage.

🦴 Daily Dino Mission: A daily goal tracker featuring a custom fossil-footprint stamp. Checking off your mission triggers confetti, custom sound FX, and saves your progress for the day.

📜 Fossil Fact Card: Randomly cycles through real dinosaur trivia, era tags, and discovery details every day (or hit shuffle whenever you want to learn something new).

🎨 4 Prehistoric Themes: Switch instantly between Jurassic Jungle, Cretaceous Desert, Volcanic Wasteland, and Ice Age Tundra.

🔊 Procedural Web Audio Engine: 100% self-contained sound effects (roars, chimes, ambient sounds) generated on-the-fly using the Web Audio API—zero external media files required!

🌋 Hidden Easter Egg
Think you found everything? Try typing dino or rawr anywhere on your keyboard while on the page to trigger an apocalyptic volcanic invasion event.

🛠️ Built With
HTML5: Clean structure with modular inline SVGs.

CSS3: Custom CSS variables, glassmorphism visual effects, dynamic theme palettes, and smooth 60fps keyframe animations.

Vanilla JavaScript (ES6+): Zero frameworks, zero external dependencies, 100% pure JavaScript logic.

Web Audio API: Real-time sound synthesis for roars, UI clicks, and ambient soundscapes.

Local Storage API: Remembers your custom shortcuts, active theme selection, and daily mission completion status across sessions.

How to Run It Local:-
1) Download or copy the index.html file.

2) Double-click index.html to open it in your browser of choice (Chrome, Edge, Firefox, Brave, Safari).

3) (Optional) Set index.html as your browser's default New Tab page using any custom tab extensions!
